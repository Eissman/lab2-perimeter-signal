# Лабораторная работа № 2
## Приём и предварительная обработка сигнала для комплекса защиты периметра

Учебный проект реализует программную модель датчика вибрации ограждения. Вместо реального оборудования генерируется цифровой сигнал, который дискретизируется, проходит валидацию, помещается в ограниченный буфер и сглаживается экспоненциальным скользящим средним EMA. В результате создаются CSV-файл и график сырого и сглаженного сигналов.

### Используемые параметры

Принят **вариант 1** из методических указаний:
- амплитуды: `A = (1.0, 0.5, 0.25)`;
- частоты: `F = (0.1, 0.1, 0.4) Гц`.

Модель сигнала:

`X(t) = Σ Aᵢ · sin(2π · Fᵢ · t) + ε(t)`,

где `ε(t)` — воспроизводимый случайный шум. Частота дискретизации по умолчанию — 20 Гц; длительность — 20 секунд; период EMA `N=10`, поэтому `alpha = 2 / (N + 1)`. Буфер хранит последние 100 сырых отсчётов, при этом полный ряд сохраняется в CSV.

### Требования

- Python 3.10 или новее;
- пакеты из `requirements.txt` (для построения графика нужен `matplotlib`);
- Git для контроля версий (не обязателен для запуска кода, но нужен для части задания по репозиторию).

### Запуск в Windows

1. Установи Python с официального сайта https://www.python.org/downloads/ и при установке отметь `Add Python to PATH`.
2. Открой папку проекта в VS Code или открой терминал в папке `Lab2_Perimeter_Signal`.
3. Установи зависимость:

   py -m pip install -r requirements.txt
   py src\perimeter_signal.py

4. Запусти:

   `python src/perimeter_signal.py`

5. Результат появится в папке `results`:
   - `perimeter_samples.csv` — все отсчёты с исходным и сглаженным значениями;
   - `perimeter_signal.png` — график двух сигналов.

Дополнительные параметры можно задать так:

`python src/perimeter_signal.py --sample-rate 20 --duration 20 --period 10 --buffer-size 100 --noise 0.15`

### Запуск тестов

Из корневой папки проекта:

`py -m unittest discover -s tests -v`

Тесты проверяют гармоническую модель, параметры EMA, ограничение буфера, проверку невалидных значений и число отсчётов при заданных частоте и длительности.

### Связь с лабораторной работой № 1

В первой работе спроектирован интеллектуальный комплекс защиты периметра и выделены адаптер источника, модуль приёма, корреляция событий, хранилище и аудит. Здесь реализуется программная модель источника и ранние этапы конвейера обработки. Реальный датчик можно подключить позднее, заменив `harmonic_signal`/генератор данных адаптером устройства, сохранив проверку, буферизацию и сглаживание.

В текущем варианте сглаживание — **предварительная обработка**, а не алгоритм принятия решения об обнаружении проникновения. Сглаженный массив может быть передан следующему модулю корреляции, описанному в лабораторной работе № 1.
